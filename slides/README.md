# Supports projetés

Un support par journée, disponible en **PowerPoint** (`sources/*.pptx`, modifiable)
et en **PDF** (à projeter tel quel). Les logos officiels (DGCI, Ministère) sont
dans `sources/assets/`.

| Fichier | Journée | Modules couverts |
| ------- | ------- | ---------------- |
| `J1-fondamentaux.pdf` | J1 — Fondamentaux du langage | 01, 02 |
| `J2-fonctions-structures.pdf` | J2 — Fonctions et structures de données | 03, 04 |
| `J3-fichiers-robustesse.pdf` | J3 — Fichiers, formats et robustesse | 05, 06, 07 |
| `J4-objets-pandas.pdf` | J4 — Objets et analyse de données + lancement du projet | 08, 09 |
| `J5-integration-projet.pdf` | J5 — Intégration, soutenances | 10, projet-final |

Chaque deck suit le même déroulé : couverture → objectifs (avec le fil de la
semaine) → concepts avec code du dépôt → TP du jour → « à retenir » et annonce
du lendemain.
