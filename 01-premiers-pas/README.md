# 01 — Premiers pas

**Objectifs** : lancer Python, manipuler variables et types de base, formater
des chaînes de caractères.

## Déroulé

1. Le REPL : `uv run python`, calculs, `print()`, `type()`
2. Variables et types : `int`, `float`, `str`, `bool`
3. Chaînes : concaténation, f-strings, méthodes (`upper`, `strip`, `replace`)
4. Entrées utilisateur : `input()` et conversion

## TP

Complétez `tp_premiers_pas.py` aux endroits marqués `À COMPLÉTER`, puis :

```bash
uv run python tp_premiers_pas.py
```
