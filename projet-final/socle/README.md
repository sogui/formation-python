# Socle du projet — mode d'emploi

1. Copiez ce dossier dans le dépôt de votre groupe.
2. Exécutez-le tel quel : il doit charger les données puis s'arrêter sur
   `NotImplementedError` — c'est normal, c'est votre point de départ.
3. Remplissez les blocs « À VOUS DE JOUER » dans l'ordre :
   `valider` → `traiter` → `restituer` → options `argparse`.
4. Le module `10-integration/pipeline.py` est votre modèle : même structure,
   entièrement rédigé.
